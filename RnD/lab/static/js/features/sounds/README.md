### 9 Frontend — sound tuner

**Sound tuner** (v26.1.16, `js/features/sounds/sounds.js`; panel `#secSounds` in the **middle section**, `#main`, under the Audio / Overlay panels). One row per sound kind (`#sndRows tr[data-kind]`, order: collision-left, -center, -right, crosswalk-in, crosswalk-out, proximity): a **low ↔ high pitch slider** on a log scale (0…1000 → 150…2000 Hz, shown as `N Hz`), a **duration** field (ms), a **repeat interval** field (s; disabled for crosswalk-in, which is one tone) and a **▶ test** button that plays that sound inside the click with the values shown (`AudioEngine.testSound`: collision kinds ~2 s of beeps at the 5-step rate, proximity chirps every interval, crosswalk-out two tones `interval` apart, crosswalk-in one; panned left / right for the sector kinds). Below: **Speech speed** (`#sndSpeech`, 0.5×–2.0×, default 1×) with a ▶ test (speaks "speech test" at that rate). Every change updates the player at once and is saved to the server profile after a 400 ms debounce (`PUT /api/sounds`; status `#sndStatus`: Saving… / Saved for every device.). **Live vs re-score:** pitch, duration and speech speed apply to playback live — the player overrides each tone event's `frequencyHz` / `durationSeconds` by its kind (a continuous chunk keeps its length) and multiplies the speech rate by the speed (clamped 0.5–2); the **intervals** shape the tone schedule, so an interval change shows **Apply timing to this run** (`#sndApply`), which saves, re-runs the collision pass (`POST /api/runs/{id}/collision`, which reads the profile; progress in the Collision settings line and `#sndStatus`) and reloads the run. **Reset sounds to defaults** (`#sndReset`) deletes the profile. All speech guards (system-voice rule, watchdog, stuck notice, priority queue and lateness drop, client-log diagnostics) are untouched; the speed only multiplies the rate. E2E hook: `window.__labAudio` (the engine; tests clear the page's profile with `setSounds({}, 1)` so injected events sound as written).
