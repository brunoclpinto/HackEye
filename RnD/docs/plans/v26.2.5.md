1. **0 s: the first frame has no depth scale** (`depthScale: null` in hazards frame 0; it is 0.29–0.30 from frame 1 on), so only
   the bases that stand on the ground are placed, and they use the horizon distance. The facade on the right gives 72 cells.
2. **Scatter:** each object base is one edge pixel, and its distance is the depth (or ground+depth fusion) of that single pixel.
   Edge pixels mix the wall's depth with the depth of what is below or behind it, and bases that sit on a sign, pole, vegetation,
   vehicle or sky (most of them: "below" counts above) are not ground contacts at all. The result is horizontal dashes spread from 3
   to 20 m instead of one line at the facade (renders: the object layer at 105 s and 120 s is a cloud of red dashes).
3. **Hidden by the surface:** the combined map (what the Lab paints and the rules read) is the argmax of all votes. A thin wall line
   loses its cells to the sidewalk / road / terrain votes projected there through the horizon, even with `objectVoteGain` 2. At 115 s,
   8,570 object cells become 1,492.

## Changes

### 1. Frame 0 gets a depth scale
- Find why `ds` is None on the first frame of the collision pass (`src/collision.py` ~3683) and seed it from that frame's own
  estimate when the run has metric depth, so `hazards.json` frame 0 carries a scale like frame 1.
- Worldmap fallback (offline `build` and online): a frame without `depthScale` uses the nearest known scale of the run (offline:
  the first known one; online: the last known one, or none on frame 0 if seeding failed).

### 2. Wall faces from image columns (`faceClasses`, new in `worldmap.json`)
`faceClasses`: building, barrier wall, barrier fence, barrier guard-rail, divider, barrier, structure bridge, structure tunnel
(the wall-like set the collision pass already judges; reuse it if it is the same list).

For every image column and every vertical run of a face class that has a base:
- **Distance:** the median depth of the bottom `faceDepthRows` (default 6) rows of that run, in the same class, times the depth
  scale. The edge pixel is no longer read alone. In ground+depth / ground-contact modes keep the current fusion, but only for bases
  that stand on a surface (contact); other bases use the depth median.
- **Bases on sky:** dropped (the class above sky is not on the ground).
- **Column smoothing:** across neighbouring columns of the same class run, take a running median over ±`faceSmoothCols` (default 3)
  columns and drop a column whose distance differs from it by more than `faceOutlierFrac` (default 0.25).
- **Connected face:** adjacent kept columns whose distances differ by less than `faceJoinFrac` (default 0.2) are joined by a
  rasterised line in the map, so a facade becomes a continuous line, not dashes. The line is `faceThicknessM` (default 0.3 m)
  thick, extended away from the user along the ray (the face plus a little solid behind it).
- Non-face objects (pole, sign, traffic light, sidewalk obstacle, vegetation) keep their current base placement, but their
  distance also uses the bottom-rows median instead of the single edge pixel.
- `Observer.object_bases` stays the API the collision pass reads (`b_rr`, `b_cc`, …): it returns the smoothed, kept points; the
  line fill is only in `observe`.

### 3. Objects are not hidden by the surface
- In `Fusion.snapshot` (combined classes): a cell is the winning object class when the object layers' decayed weight is at least
  `objectWinShare` (default 0.35) of the cell's total and above the floor; otherwise the argmax as today. `conf` for such a cell is
  computed from the object share.
- The rules read the combined map (`solid`, `wall_solid`, ghost tests), so this changes what they see. That is intended: they see
  the walls the image sees. Measure the change (below) and list it; don't block on it.
