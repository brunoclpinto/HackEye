## A. Sounds
1. **Notification kinds** (tone and beeps events carry `kind`):
   - `crosswalk-in`, `crosswalk-out` (existing).
   - `collision-left` / `collision-center` / `collision-right` replace `collision`. The kind comes from the item's clock quarter at each tone: center = 11:45–12:15 (quarters −1…+1); left = 9:00–11:30 (quarters ≤ −2); right = 12:30–3:00 (quarters ≥ +2).
     - The user wrote left "9:00–11:45" and right "12:15–3:00"; the shared boundaries 11:45 and 12:15 belong to center.
     - An episode whose item changes sector switches kind per tone.
   - `proximity` (the soft approaching-person sound from v26.1.13). The user's list doesn't name it: **keep it, tunable like the rest, and ask the user in the done-mail whether to drop it.**
2. **Default sounds** (all different):
   - collision-center: 880 Hz, 80 ms, the existing parking rate.
   - collision-left: 660 Hz.
   - collision-right: 1100 Hz.
   - crosswalk-in: 330 Hz, 600 ms.
   - crosswalk-out: 330 Hz, 2 × 200 ms with a 120 ms gap.
   - proximity: 440 Hz soft double chirp.
   - The existing stereo pan by bearing stays.
3. **Sound profile:** one Lab-wide profile, stored server-side in `debug/lab/display/sounds.json` (it survives version wipes, like the display view).
   - **API:** `GET /api/sounds` and `PUT /api/sounds`; the defaults come from `collision.json` `tones`.
   - **Fields per kind:** `pitchHz`, `durationMs` and `intervalS`, plus a global `speechRate` (0.5–2.0, default 1.0).
   - **Meaning of `intervalS`:**
     - collision kinds: the repeat interval at 5 steps (the far end). The parking table (`bySteps`) is scaled proportionally.
     - crosswalk-out: the gap between its two tones.
     - proximity: the repeat period.
     - crosswalk-in: unused (single tone).
4. **Tuner UI:** in the **middle section** (the panels under the video in `#main`), a "Sounds" panel.
   - **Rows:** one row per kind, with pitch (a low ↔ high slider on a log scale, 150–2000 Hz, with the Hz shown), duration (ms), repeat interval (s; disabled where unused) and a ▶ test button. The test button plays that sound inside the gesture with the current values; for collision kinds it plays ~2 s at the 5-step rate.
   - **Speech speed:** a "Speech speed" bar (0.5×–2.0×, default 1×) with a ▶ test that speaks "speech test" at that rate.
   - **Saving:** values save to the profile (debounced PUT).
   - **Live vs re-score:** pitch, duration and speech speed apply live to playback (the client overrides event fields by kind). Interval changes need the tone schedule rebuilt, so show "Apply timing to this run", which re-runs the collision pass (`POST /api/runs/{id}/collision`) and shows progress. The collision pass reads the profile's intervals.
   - **Guards:** keep every speech guard. The speech rate multiplies the existing rate; the player queue's 1 s lateness rule stays.
5. **Review panel:** the Notification review panel shows the new kinds, e.g. "beeps · left · person at 11:30 · 4→2 steps", "⇥ crosswalk in".
