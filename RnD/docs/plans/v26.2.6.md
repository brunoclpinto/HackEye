## Diagnosis (Opus, 2026-10-30)

- **Build button:** the analysis job runs `collision_pass` and finishes; `worldmap_pass` only runs from `POST /worldmap` (the button)
  or from a collision re-run when a map already exists.
- **"Beyond 20 m":** `cellText()` (lab/static/js/worldmap.js) appends every hazard of the frame past 20 m ahead or 10 m to the side,
  whatever cell is selected. It says nothing about the cell.
- **Object not selectable:** at 0 s the sidewalk-obstacle is a danger item at 1.58 m ahead / 0.58 m right, drawn as a dot. The map
  cells there are empty or sidewalk (`/worldmap/cell` at 105,183–185 = none; 104,185 = sidewalk), so the readout leads with
  "Region: flat sidewalk · Object: none". The item is only on a later "Item:" line, and only within 0.3 m of the cell centre,
  while the drawn dot (and its danger ring) is larger than that.
- **Building dots:** every static hazard gets a dot, buildings too. The building already shows as wall-coloured cells and wall lines.

## Changes

1. **Map built with the run.** `_run_job` (lab/analysis.py) runs `worldmap_pass` right after `collision_pass`, before the run is
   marked done (a failure is logged; the run is still done). Every other caller that recomputes the collision pass (the
   `POST /collision` re-run, and any other `collision_pass(` caller) rebuilds the map always, not only when one exists.
   `POST /worldmap` stays as an API. UI: the `#wmBuild` button and its code are removed; a run without a map says
   "This run has no world map."
2. **Wall lines always on.** The `#wmRules` checkbox and its localStorage key are removed; the face/edge overlay is always drawn.
3. **Readout:** the "Beyond 20 m …" line is removed. The box shows only the cell's lines (place, region, object, items).
4. **Selectable items.** A click first hit-tests the current frame's drawn item markers in canvas pixels (the drawn radius, at
   least 8 CSS px; the nearest wins). A hit snaps the selection to that item's cell, and the readout's `Object:` line names the item
   (class · role · track · distance source, plus the map's object class when the cell has one). Without a hit, the Object line is
   the map's object class, else the nearest item within the drawn marker radius of the cell, else "none".
5. **No markers for massive structures:** items of class building, structure bridge and structure tunnel are not drawn as dots
   (no circle, danger ring, snap line or cross). Their cells and wall lines show them; a click on them still reads the building.
